# Project Master Root Instructions

This directory is a managed Project Master root. Open and run agents from this directory so both sibling repositories remain accessible.

Before project status, brainstorming, planning, implementation, or review work, read `.project-meta/project/README.md`, `.project-meta/project/project.yaml`, and `.project-meta/project/STATUS.md`, then inspect the relevant underlying artifacts. Use the globally installed Project Master skills when applicable.

Write project intent, decisions, coordination records, and durable evidence only under `.project-meta/project/`. Write disposable UI prototype work only under `.project-meta/prototype/`. Write implementation only under `workspace/`. Never add Project Master files or references to the `workspace/` repository.

The sole project owner approves consequential intent. Routine authorized work inside approved boundaries may proceed automatically.
